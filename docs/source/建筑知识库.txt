# Minecraft 建筑优化知识库（全集版）

> 用途：DeskPet 建筑识别系统的「建筑优化知识库」。程序（BuildingScore）按
> 「当前建筑类别 + 最弱子项」从本库抽 2~3 条，交给桌宠端 AI 组织语言（隐式，不泄分）。
> 本文件是**全集**，供人工核查；程序端当前内嵌的是按类别/弱点抽取的**子集**，可逐步并入本库。
>
> 结构：壹 总则 │ 贰 部件与元素专项 │ 叁 特殊方块工具箱 │ 肆 建筑类型 │ 伍 建筑风格
>      │ 陆 弱点针对性优化 │ 柒 锦上添花 │ 捌 来源
>
> 内容主要整理自 Minecraft 中文 Wiki《教程:屋顶类型》《教程:屋顶建造指南》《教程:房屋类型》
> 及公开建筑教程/社区设计要点（窗户、墙面、雕花设计合集等）。

壹、总则（先立骨架再谈细节）

【比例与体量】
- 高:长:宽接近 1:1.6:1（黄金感）或横向舒展 1:2:1 最耐看；过细像针、过扁像地砖都不好。
- 屋顶建议高度控制在 1~2 层楼高（约 5~7 格）；超过一层就好考虑在屋顶里再加层房间。
- 建筑宽度最好做**奇数**，这样人字形/尖屋顶能正好收在中轴造型（门/窗）上方。

【材质三区三层】
- 把**承重柱、墙面、地板**的主材质分开：柱用深色原木/石砖、墙用浅木板/砖、地板深板/地毯，
  三区三层，层次感立现——别一整栋都用同一种方块。

【主题先行】
- 先定一个主题/风格（中式、和风、现代、哥特、乡村……），再把窗户、屋顶、材质都往主题上靠，
  比东拼西凑强得多。

【一、屋顶】　（最影响观感的部分，Wiki 教程内容）
- 屋顶类型：平屋顶 / 平台屋顶 / 单坡(棚)顶 / 人字形 / 盐盒式 / 天窗屋顶 / 斜脊屋顶 /
  半四坡 / 荷兰山墙 / 披屋屋顶 / 复折式 / 鸥翼 / 折线形 / 钟型(阀盖) / 锯齿状 / 监视台 /
  尖屋顶 / 蝴蝶顶。
- 平顶最省事但要用心：屋顶上加一圈**边界**（台阶、反向楼梯、铁栏杆、空白告示牌）做檐槽/护墙，
  普通的平顶立刻变精致（参考村庄铁匠铺）。
- 人字形屋顶(Gable)适合小房（宽 <12 格）；斜脊/金字塔顶(Hipped)适合正方形；复斜/折线形扩大阁楼体积。
- 屋顶斜度：63.4°=两个方块、45°=楼梯、26.5°=交替上下台阶；奇偶宽要匹配屋顶收束处。
- 大建筑(>15×15)别用单一屋顶：把不同**部位各配一个屋顶**再连接成 T/L/H 形，从最高处开始逐个连。
- 屋顶窗(Dormer)：从坡顶凸出的迷你小屋+自己的小顶，增加顶楼采光与空间，样式有墙式/山墙式/斜脊式/平顶式/眼睑式。
- 屋顶装饰：
  - 顶部屋脊：用圆石墙/楼梯做脊线，宽度做奇数更稳。
  - 末端矮墙：把共用端墙高出屋面，加强邻排分隔，端部做成对称。
  - 护墙：大型建筑在屋顶四周垂直延伸一段墙，让屋顶与其余部分相称。
  - 山墙：佛兰德山墙/阶梯式山墙（乌鸦台阶）比平直山头有味道。
  - 有图案的屋顶：在瓦片里嵌图案（换色/楼梯混排）作为主题。
  - 外墙立面：朴素建筑用立面遮住不寻常屋顶形状，让它与邻居协调。
- 屋顶材质要点：**用楼梯/台阶铺坡**是坡顶的标志（也是程序屋顶检测的判据）；
  尖顶底部用台阶铺避免缝隙；茅草顶用干草捆+黄地毯做瓦；绿色屋顶用泥土+植物。

【二、窗户】
- 三层式窗：窗沿(下) + 玻璃窗(中) + 窗楣(上)，用半砖/楼梯做出外凸立体框。
- 立体窗框：半砖上下错位，活板门做窗台/窗眉，比贴墙平板窗有层次。
- 一楼窗底：用**活板门围一小圈苗圃**（草/花/珊瑚/杜鹃），窗外有生机。
- 嵌入式窗：玻璃嵌进墙里一格深，加栅栏/铁栏杆做分格。
- 哥特/教堂窗：深色玻璃 + 石质窄高窗框，顶部尖收。
- 窗高度、位置对齐：同层窗对齐、层间错开一点，立面才有节奏。

【三、门与门廊】
- 门洞别只挖个洞：加门楣（半砖/楼梯）、门框柱（砖柱/原木柱）。
- 门廊/入口：楼梯台阶上升 + 立柱撑顶 + 栅栏扶手，入户仪式感；坡顶门廊用披屋顶盖住。
- 双开门/大门：宽入口配对称门框 + 上方招牌/横梁。

【四、地基与支撑】
- 柱脚/悬挑地基：建筑底部抬高半格，一圈柱脚落下，底部留柱间凹槽，落地感立刻不同。
- 阶梯式地基：地基随地形逐级降低，比死平一片有层次。
- 地基分层：底部深色（石基/深板岩），往上过渡到主体，材质切换处用半砖/楼梯缓冲。

【五、墙与立面】
- 壁柱：把柱子贴墙凸出半格，隔一段一根，打破一面平墙。
- 窗沿/飞檐/腰线：每层加一圈外凸的楼梯/半砖，楼层界线分明。
- 凹凸交错：一排凸、一排凹，或局部伸出一格做凸窗/飘窗，立面由平转立体。

【六、楼梯、半砖、栅栏、玻璃（特殊方块用法，见叁）】

【七、采光与灯光】
- 白天靠窗/天窗采光；夜里用萤石/海灯/火把/灯笼做檐口灯带、廊柱灯。
- 室内嵌灯：墙里嵌萤石/灯笼，地面藏光源，避免密闭小黑屋（尤其地下）。
- 天台/庭院点灯：红石灯 + 传感器做自动夜灯。

【八、地面与铺装】
- 室内地板分层：深色板/地毯 + 边缘半砖收边。
- 室外路径：半砖/石砖/木板鋪小径，石块+草交互更自然。
- 台阶/坡地：楼梯做坡、半砖做阶梯，比一格一格跳有用。

【九、景观与环境】
- 植物：树叶/藤蔓/杜鹃爬墙、花丛、灌木、盆栽点缀，自然风。
- 水景：水池、喷泉、小河、泳池，配石阶/踏步。
- 石头：圆石、苔石、安山岩混搭做成岩壁/假山/挡土墙。
- 围合：矮栅栏/花坛围一圈，让空地有"院落感"。

【十、阳台 / 露台 / 月台】
- 阳台：可露天/覆顶，从主墙凸出；月台正下方在屋外。
- 栏杆：栅栏/铁栏杆/半砖做沿口，外挑用梁/立柱支撑。
- 大型建筑把"外挂式阳台+露台"当呼吸点，打破大体量沉闷。

【十一、烟囱】
- 烟囱配火炉/壁炉，顶端加帽（反向楼梯），比光棍柱有生活气。

【十二、内饰】
- 功能分区：床(卧室)+储物(箱阵)+工坊(工作台/熔炉/附魔/酿造/铁砧)+红石自动化。
- 家具：桌(压力板+栅栏/活板门)、椅(楼梯靠墙)、书架墙、花盆、地毯。
- 记住：建筑外面打分主要看外立面，但内里乱糟糟也会差一口气。

叁、特殊方块工具箱（半砖/楼梯/活板门/栅栏/玻璃/等怎么用出彩）
═══════════════════════════════════════════════════════════════

【半砖 Slab】
- 窗台/窗楣/窗沿、门楣、门槛、屋檐压边。
- 夹层楼板沿口、阶梯、台阶、检修口。
- 收边：窗、门、墙顶转角处收一道，利落有细节。

【楼梯 Stairs】
- 坡顶/坡道（最常用）、屋脊、山墙、挑檐、门廊雨棚。
- 反向楼梯：屋顶凹角、拱、檐口反边。
- 转角楼梯做透视转角、柱子装饰、家具（椅子/桌子）。

【活板门 Trapdoor】
- 窗台/窗帽、窗框、苗圃围边、柜门、台阶盖、平开小窗。
- 挂在墙上做百叶/窗格，比实心墙透得更秀气。

【栅栏 Fence】
- 栏杆（阳台/桥/露台）、窗栏、柱间连接、栏杆垛口。
- 矮围栏、花坛边、篱笆。

【栅栏门/门】
- 院门、栅栏门；木门/铁门做入口搭配。

【玻璃/染色玻璃】
- 采光窗、大落地窗、嵌玻璃幕墙；染色玻璃做彩窗/天窗。

【树叶/Vines/花】
- 藤蔓爬墙、树叶装点屋檐/树冠、花盆/花坛/杜鹃，自然风格关键。
- 樱花/杜鹃丛做柔和点缀。

【地毯 Carpet】
- 屋顶瓦（茅草/瓦顶铺面）、室内地板色块、花圃/苗圃边、楼梯缓冲色。

【圆石墙/苔石墙】
- 屋脊、矮墙、护栏、假山；苔石+圆石+石砖混搭更自然。

【火把/灯笼/灯】
- 檐口灯带、点光源、夜灯；萤石嵌地/墙做隐形光源。

【栏杆/铁栏杆】
- 阳台/桥栏杆、窗格、护墙顶。

肆、建筑类型（每类给出"怎么做才好看"）

【居住·房屋 house】
- 窗户比门大而亮：立体窗框+窗台花盆；进门做小门廊（台阶+立柱+栅栏扶手）。
- 屋顶用楼梯铺坡；平顶加一圈台阶/反楼梯做檐口。
- 立面分层：石基-木身-砖角；柱/墙/地板三区分层。

【别墅 villa】
- 破开单调大面：壁柱、阳台、三段式窗；屋顶用复斜/折线形扩大阁楼+屋顶窗。
- 多翼平面：主体+侧翼+转角塔，形成 L/T 形，比矩形有层次。

【多层 multi_story】
- 楼梯间串联，半砖做楼板沿口；每层窗对齐+层间腰线，立面有节奏。

【谷仓 barn】
- 大而通透：大坡顶（楼梯铺坡）+ 门洞 + 顶部天窗/气窗；木板搭石基。

【平房 bungalow】
- 横向舒展：宽檐口（挑出楼梯/半砖）、大玻璃窗、砖柱包角，低矮也规整。

【火柴盒 matchbox】
- 救星在立面：门窗/屋檐全用半砖/活板门/楼梯组合；墙上错位嵌倒置楼梯做凹凸。

【小屋 cabin】
- 质感路线：原木+去皮原木混搭、石基、小坡顶；窗边花盆、檐下垂藤。

【高塔 tower】
- 瘦高挺拔：越往上越收（漏斗剪影），顶部加尖顶/悬崖顶；每隔几层加一圈台阶腰线。

【尖塔 spire】
- 收束：塔身递减、顶部楼梯铺尖避免空隙、底做宽基座。

【灯塔 lighthouse】
- 顶部栏杆+光源（海灯/萤石/火把），塔身红白条纹（羊毛/混凝土交替）。

【城堡 castle】
- 角塔+城墙+门楼三件套；墙顶垛口（楼梯交替）、角塔高于城墙、石拱门+吊桥感。

【城墙 wall】
- 顶部垛口（楼梯交替）、底部石砖/苔石斑驳、每隔一段加小塔或箭窗。

【边界墙 boundary】
- 低而规整：顶部半砖压边、转角立柱、中嵌栅栏/铁栏。

【桥 bridge】
- 看支撑：桥墩、拱肋、栏杆都不能少；石桥楼梯做拱肋、半砖做栏板。

【拱门 arch】
- 两柱加基座、顶部楼梯合龙、垂藤蔓；拱内嵌玻璃/灯。

【泳池 pool】
- 边缘深色石砖+半砖嵌边+一级矮梯；旁配躺椅（楼梯/半块）+遮阳伞（杆+羊毛顶）。

【喷泉 fountain】
- 三层递减水盘：中心柱+中层盘+底层池，盘沿半砖；四周对称铺砖、点海灯。

【人形雕塑 statue_humanoid】
- 基座+主体+点缀：深板岩基座衬托，加肩膀/飘带（楼梯/半砖）更有动感。

【图腾柱 statue_column】
- 层层收窄（圆柱剪影）、每层换色/圆环、顶加尖墩。

【雕像 statue】
- 胜在整体轮廓：基座、主体、顶部渐变，别让细碎块破坏剪影。

【像素画 pixel_art】
- 立面上用羊毛/混凝土色块；深色描边、边缘半砖收边，画面更清晰。

【露天家园 open_base】
- 围而不合：矮栅栏/花坛围一圈，中摆床/工作台/箱阵，生活气十足。

【地下建筑 underground】
- 注意采光：墙面嵌灯（萤石/火把）、苔石斑驳、顶部开口做采光井。

【复杂大型 complex】
- 多样屋顶组合 + 多翼平面 + 立面处理；别用单一设计一用到头。

伍、建筑风格（每种给出"用哪些方块、怎么上色"）

【现代 Modern】玻璃(青)+低饱和 + 平顶/悬挑；大量玻璃幕墙、极简几何、灰白钢木质感。
【冰雪 Snowy】白+冷+亮：白/浅蓝/冰、石英+雪+冰砖；尖顶/坡顶，晶莹。
【沙漠 Desert】沙质+暖：沙岩/橙陶/仙人掌；平顶出檐、拱窗，暖色调。
【奇幻 Fantasy】紫/粉+悬空：紫杉/紫晶/深板岩+萤石，尖顶、悬空平台、光柱。
【哥特 Gothic】暗+深灰/黑+尖顶/高耸：深板岩+黑石英+深色玻璃，窄高尖窗、飞扶壁感。
【地中海 Mediterranean】暖+亮+平顶：白墙+红陶瓦、圆拱、露台；蓝白装饰。
【和风 Japanese】木质+坡/尖顶+对称：樱花木/深色木、半砖屋檐、格栅窗、枯山水。
【中式 Chinese】红/棕+暖+对称：红砖/深木、坡顶出檐、飞檐（楼梯）、廊柱、格窗。
【乡村 Rustic】木/土+暖+坡顶/露天：原木+圆石+苔石、茅草/坡顶；田园感。
【工业 Industrial】灰+低饱和+红石：石砖+铁/铜+红石机械、天窗(锯齿顶)、厂房大跨度。
【中世纪 Medieval】石+尖顶/高耸：石砖+石英发光、城堡垛口、尖顶塔楼。
【传统木构】原木+木板、坡顶挑檐；【传统石构】石砖+深板岩、厚实稳重。

陆、弱点针对性优化（按评分弱项给出可操作手法，一项多条）

【材质丰富度 偏低（单调）】
- 梁柱/墙/地板主材质分开三区三层；木配石、砖衬玻璃。
- 转角用砖柱、檐口用陶瓦、门框用原木柱——小处换材质即成焦点。
- 同材质做变体：原木+去皮原木、石英+石英砖、圆石+苔石+石砖，细看有料。

【雕工指数 偏低（特殊方块 <5%，光秃秃）】
- 半砖+活板门=立体窗框/窗台/苗圃；楼梯=屋檐/门廊/坡顶；栅栏=栏杆；玻璃=采光。
- 门洞加门楣+门框柱；墙顶/屋脊用楼梯压边；地面嵌半砖做阶梯。
- 在墙上错位嵌倒置楼梯/半砖做凹凸，平脸立刻变生动。

【空心率 偏高（实心巨石 / 内部没做）】
- 加承重柱+梁+楼梯，用半砖做夹层楼板，把大空间分成立体小房间。
- 留挑空/天井、内部掏空分层；空间立体起来才不闷。

【空心率 偏低（空心薄壳）】
- 加厚墙身、留承重柱和横梁；柱子深色、墙体加厚、梁换色，结构更扎实。

【垂向分层 混乱（各高度材质随机混杂）】
- "底深-中浅-顶亮"三层：石基/深色底座、浅色主体、亮/深色屋顶。
- 过渡用楼梯/半砖/台阶做窄混搭带；每层一套主材质，别五彩斑斓。

【邻近颜色对比度 过高】
- 亮暗/高饱和只做点缀（窗框/檐线/门楣），主体用同明度过渡色衔接。
- 相邻强对比色块之间垫一段中性过渡（灰砖/原木），视觉就不生硬。

【支撑逻辑 偏低（地基直接铺地）】
- 围一圈柱脚或做阶梯式地基；悬挑阳台/露台用梁撑起、底部不做死墙。

【外立面起伏度 偏低（墙面平板）】
- 壁柱、窗沿、飞檐；凹凸交错铺面；门窗换成凸出的门廊/飘窗。

【体态比例 异常（细针 / 地砖）】
- 细高：加宽基座+横向腰线/平台；过扁：加高/加塔楼/上坡顶再挑檐口。

【比例对称 失衡】
- 做中轴对称（中式/和风/现代对称型）；非对称型也要"视觉平衡"，别头重脚轻。

柒、锦上添花（整体不错时，给进阶点缀）
═══════════════════════════════════════════════════════════════

- 窗外做立体窗框+窗台花盆；或给屋顶开个屋顶窗(Dormer)。
- 墙角/屋檐垂点藤蔓、树叶、杜鹃，添一抹自然气。
- 夜里用萤石/海灯/火把做檐口灯带，白天看材质、晚上看光影。
- 给地坪做一圈矮苗圃（活板门围边+草/花），窗下不空。
- 屋顶加屋脊/山墙/护墙，顶部的细节最容易出彩。
- 大建筑做"多屋顶组合+阳台露台+立面处理"，避免一马平川。
