# MC 百科（mcmod.cn）收录提交包

> 为什么做：中文 MC 圈**搜模组的入口**，收录后有持续自然搜索流量。
> 流程已核实：注册（支持 QQ 登录）→ 首页右侧「添加模组」（直达 <http://www.mcmod.cn/class/add>）→
> 普通用户提交需填 **2 位图片验证码**（表单底部，提交按钮附近）→ 编辑员审核（几天内）。

## 一、操作步骤

1. 注册/登录：<http://www.mcmod.cn/reg>（支持 QQ 登录；新账号是「百科用户」，可以提交，只是要过审）
2. 打开 <http://www.mcmod.cn/class/add>，按下面第二节逐项填
3. **封面上传**：百科要求 240×150。已备好 [`docs/images/deskpet-mod-cover-240x150.png`](../images/deskpet-mod-cover-240x150.png)。
   传法：编辑器「图片」按钮 → 本地上传 → 上传后单击这张图 → 再点「图片」按钮切到**远程图片**选项卡 →
   拿到站内图片地址 → 粘到「封面」栏（百科要求尽量用站内地址）
4. 提交前把表单内容**复制一份到记事本**（万一验证码报错，刷新可能清空已填内容）
5. 提交 → 在 <https://www.mcmod.cn/verify.html> 或「个人中心 → 我的编辑」看审核状态
6. **收录后**：把 `https://www.mcmod.cn/class/xxxxx.html` 补进仓库 README 顶部和 GitHub About

## 三、简介正文（整段复制到编辑器）

> DeskPet 桌宠的配套模组：把你的 Minecraft 世界「讲给」桌面上的 AI 伙伴听。
>
> 它做两件事。**① 游戏事件采集**：把你在游戏里的行为（挖掘、击杀、获得物品、受伤、死亡、
> 进度、聊天、移动）按 20 秒聚合成事件窗口，并按重要程度分级，让桌宠知道什么时候值得开口。
> **② 建筑识别**：记住你放置的方块，纯本地做三维结构扫描（墙体/房间/屋顶类型/对称性），
> 配色分析用真实纹理取色（1268 种方块），可分类到小屋/高塔/城堡/桥/雕像/像素画/农场等约 25 类，
> 推断建筑风格，给出针对性改进建议；还能在你**建造过程中**就猜出你在建什么、建到哪一步。
>
> ⚠️ **注意：本模组只是数据采集端，单独安装不会改变游戏内容、也没有可见界面**——
> 采集的数据写入 `.minecraft/deskpet/`，需要配合桌面程序 **DeskPet 桌宠**
> （Windows / 开源 / MIT，<https://github.com/oyxdsg/Multimodal-AI-Companion>）才能看到效果
> （桌宠在桌面说话、点评你的建筑、陪你聊天）。
>
> 环境要求：Minecraft 26.2（Fabric）、Java 25、Fabric API。
> 单人/局域网世界完整可用；远程多人服务器上服务端事件（击杀/受伤/破坏/建筑采集）不可采集，
> 进度、聊天、合成、拾取仍正常。
>
> 数据全部只写在本机，模组无任何网络请求与遥测。
>
> 姊妹项目 **SmartMaid**（<https://github.com/oyxdsg/SmartMaid>）：同一作者的开源女仆模组，
> 女仆可以在游戏内跟随、挖矿、战斗、被玩家对话唤醒——与桌宠程序联动即形成完整闭环。
>
