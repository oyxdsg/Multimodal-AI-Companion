```
SmartMaid 是一个 Minecraft Java 版 26.2（Fabric）的 AI 女仆模组：指令召唤一只属于你的女仆，
她会跟着你跑、替你砍树挖矿、帮你打怪挡箭，还能用聊天栏跟她说话——她不只是回一句话，
而是听完真的会去干。规则引擎驱动，安全优先、毫秒级响应，AI 只做兜底增强；
完全开源（GitHub 搜 oyxdsg/SmartMaid）。

【召唤与归属】
· /summonmaid 召唤，每名玩家仅限一只，召唤即归属，无需驯服
· 退出游戏女仆消失，但装备与物品栏每 5 秒自动持久化，重新召唤原样恢复
· 右键坐/站：坐下即吸附脚下支撑面（含半砖、台阶顶），完全静止不被推走

【她真的会打仗】规则驱动战斗，优先级 盾 > 吃 > 远程 > 近战 > 逼近：
· 盾牌格挡：检测到箭矢将命中、苦力怕将爆炸 → 当场举盾（去掉了原版 0.25s 架盾前摇，贴脸箭也挡得下）
· 近战走位：按武器攻速节奏出手，2.7~3.2 格死区自动前进/后退，墙角侧移绕行，背对跳上高台
· 远程：自写弓箭蓄力 + 边退边射（kite）
· 半血自动进食回血；主人被打无条件反击；箭矢永不误伤玩家

【跳跃寻路】自写寻路 + 离线解表：跨 1~3 格沟、上 1 格高台、下跳 1~3 格，
起跳点/朝向按障碍场景参数化，运行时只查表不做物理计算——她跟图式地跟你走，不卡墙角

【AI 任务系统】/maidtasks 指挥干活：攻击（可指定目标）、护卫、喂食、挖矿（有挖掘过程）、
耕作、建造、收集、原地合成、烧炼……AI 还能用「原子指令脚本」自由组装多步任务：
找树→砍倒→范围递增→循环续找直到凑够原木，每步回执结构化，砍木头这件事她是真去砍的

【背包与物品】背包布局与玩家完全一致（41 格），界面左上角实时渲染女仆模型；
换手/收纳/穿戴/交换一个 transfer 指令搞定；两步存取箱子（真实开箱动画 + 智能堆叠）

【设置面板】木质「女仆管理」GUI：交互距离、护卫模式、最大生命、喂食/回血速度、死亡掉落，点按即切换

【对话与联动（可选）】不装任何东西她也能独立干活；配合同一作者的开源桌面程序
DeskPet 桌宠（AI/语音/气泡），女仆就长出了嘴——聊天栏说话她用中文回你，还会语音朗读。
桌宠仓库：https://github.com/oyxdsg/Multimodal-AI-Companion

[此处插入截图 1：女仆背包界面（左上角有女仆实时模型）]
[此处插入截图 2：女仆管理面板]

【安装】Fabric Loader（26.2）+ Fabric API，把 jar 丢进 mods 即可。无配置文件。
注意：召唤/任务等命令需要管理员权限（单人存档开作弊即可，服务器上由管理员召唤）。

【环境要求】Minecraft 26.2（Fabric）· Java 25 · Fabric API
```
