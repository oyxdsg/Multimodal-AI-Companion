```
DeskPet Mod 是一个 Minecraft Java 版 26.2（Fabric）配套模组，配合开源桌面 AI 伴侣程序「DeskPet 桌宠」使用：模组负责把你在游戏里发生的事采集成本地数据文件，桌宠程序读取后会在桌面上开口说话——点评你刚建好的房子、在你挖到钻石时来一句恭喜、陪你边玩边聊。

【先说清楚】本模组只是数据采集端，单独装进游戏没有可见界面、也不改变玩法；需要配合桌宠程序（Windows / 开源 / MIT）才有完整体验。链接见文末。

【它采集什么】
· 每 20 秒把你的行为聚合成事件窗口：挖掘、击杀、获得物品、使用物品、受伤、死亡、进度、聊天、维度切换、移动距离
· 每个窗口按重要程度分级（重要/普通/低），桌宠据此决定要不要开口——你专心干活时它不打扰，出大事它才说话

【建筑识别（纯本地，最有意思的部分）】
· 记住你放置的每个方块，对你正在建的建筑做三维结构扫描：墙体、房间、屋顶类型（平顶/人字/尖顶/穹顶）、对称性、材料分层
· 配色分析用真实纹理取色（1268 种方块），不是关键词猜的
· 可分类到约 25 类：小屋、别墅、高塔、灯塔、城堡、城墙、桥、拱门、水池、喷泉、雕像、像素画、农场、牧场、地下建筑……
· 推断建筑风格：乡村/现代/哥特/日式/中式/地中海/工业……
· 三维评分（结构/装饰/配色）+ 针对性改进建议
· 建到一半就能猜出你在建什么、进度如何——桌宠在你施工过程中就会点评，不用等盖完

【安装】
1. 装 Fabric Loader（26.2）+ Fabric API
2. 把 deskpet-mod-2.0.0.jar 丢进 mods 文件夹
3. 下载并运行 DeskPet 桌宠程序（Windows），在它的设置里指向你的 .minecraft 目录即可联动
（模组无配置文件，装上即用）

【数据写到哪】全部在本机 .minecraft/deskpet/ 下：事件窗口 jsonl（自动清理）、建筑快照 latest.json、
历史建筑 history.jsonl、方块增删日志。模组零网络请求、零遥测、无账号。

【已知限制】建筑识别是服务端采集：单人/局域网世界完整可用；远程多人服务器上击杀、受伤、
破坏、建筑采集拿不到（进度、聊天、合成、拾取不受影响）。上服务器请遵守该服的 mod 规则。

【环境要求】Minecraft 26.2（Fabric）· Java 25 · Fabric API
```
