# 动画素材目录

本目录存放桌宠的动作素材。**完整动画素材不随主仓库发布**（体积 248MB），
仓库只保留：

```
assets/
├── README.md          # 本文件
├── _static/idle.png   # 内置静态图（大肥鱼待机帧；角色形象为 CC BY-NC-SA 4.0，见 NOTICE）
└── <动作目录>/          # 可选：自备动画帧（gitignore，不随仓库）
```

## 没有动画素材会怎样

**静态模式**：宠物显示 `_static/idle.png` 这一张静态图，可拖动、可聊天、
气泡/语音/游戏联动全部正常，只是**不播放动作动画**。不会崩溃。

## 怎么补回动画

三条任选：

1. **官方动画资源包（最省事）**：到配套仓库
   [`Multimodal-AI-Companion-Assets`](https://github.com/oyxdsg/Multimodal-AI-Companion-Assets)
   的 Releases 下载 `deskpet-animation-assets-v1.0.0.zip`（247MB / 17 动作 / 1663 帧），
   解压到**本目录**即可（zip 内就是 `<动作>/frame_0000.png` 这层结构）。也可以只解压需要的几个动作
   —— 程序按动作 key 缺失回退静态图，不会崩。
2. **自己生成**：用 [`../../deskpet-tools/`](../../deskpet-tools/) 把绿幕视频转成动作帧，或按
   下面规范自备 PNG 帧序列。
3. **角色包**：用工具打包成角色包放入 `../skins/<角色id>/`，在设置 →「皮肤」切换。

## 动作目录规范

每个子文件夹对应一个动作，透明背景 PNG，命名 `frame_0000.png` 递增：

| 目录名（示例） | 动作 key | 说明 |
|---|---|---|
| `坐地上生气` | `idle` / `angry` | 待机（内置静态图来源） |
| `正面` | `front` | 正面站立 |
| `背面` | `back` | 背面 |
| `侧面` | `side` | 侧面（走路，可镜像） |
| `坐下` / `起身` | `sit` / `rise` | 坐姿与过渡 |
| `思考` `开心` `哭泣` `害羞` `惊讶` `站着睡着` | `think` `happy` `cry` `shy` `surprised` `sleep` | 表情动作 |
| `跳跃` | `jump` | 位移动作，含 `traj.json`（dy 轨迹） |
| `打滚` | `roll` | 位移动作，含 `traj.json`（dx/dy 轨迹） |
| `跳舞` | `dance` | |
| `转向` | `turn` | 2 帧 |

目录名 → 动作 key 的映射见 [`../config.py`](../config.py) 的 `ACTIONS`。
程序自动裁剪透明边、统一缩放、脚部贴底对齐；位移动作另读 `traj.json`。

> 处理流程详见 [`../视频处理成图片成为宠物动作.md`](../docs/视频处理成图片成为宠物动作.md)。
